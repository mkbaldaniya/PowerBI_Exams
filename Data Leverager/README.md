# 📖 Overview

**Data Leverager** is a Business Analyst ETL project built in **Microsoft Power BI Power Query**.

The objective is to extract, clean, transform and integrate data from multiple sources before it is used for reporting.

---

# ✨ Highlights

- 🌐 HTML Table Import
- 📁 Folder Data Import
- 📊 Excel Data Import
- 👨‍💼 Employee Dataset Integration
- 🧹 Data Cleaning

- ➕ Append Queries
- 🔀 Pivot & Unpivot
- 📈 Aggregations
- 📅 Date Transformations
- ⚙ Parameters
- 🔁 Refresh Simulation
